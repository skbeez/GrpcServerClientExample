# grpc-web-app

React app built with [Vite](https://vite.dev).

## Available Scripts

### `npm start`

Runs the app in development mode at [http://localhost:3000](http://localhost:3000). The page reloads when you make changes.

### `npm test`

Runs the tests once with [Vitest](https://vitest.dev). Use `npx vitest` for watch mode.

### `npm run build`

Builds the app for production to the `dist` folder.

### `npm run preview`

Serves the production build from `dist` locally.
